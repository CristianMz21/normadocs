# NormaDocs v0.2.2 — Open Source Readiness and Community Setup

This release focuses on making NormaDocs a friendlier, more transparent
open source project for contributors and users. It does not introduce
breaking changes and does not change the public CLI or Python API.

## Highlights

- New top-level contributor files: `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`
  (Contributor Covenant v2.1), `SUPPORT.md`, `GOVERNANCE.md`,
  `MAINTAINERS.md`, `docs/COMMUNITY.md`, and `ROADMAP.md`.
- New `CITATION.cff` (CFF 1.2.0) for academic citation.
- GitHub community setup: 22 labels, 3 milestones (`v0.2.2`, `v0.3.0`,
  `v0.4.0`), 10 community issues (#8–#17), Discussions enabled, and 14
  repository topics including `latam`, `apa`, `icontec`, `ieee`,
  `academic-writing`, and `open-source`.
- Strict typing blockers resolved across the project (no `# noqa`, no
  `# type: ignore`, no weakened strictness).
- OCR lint and mypy violations from the recent OCR commit fixed; the
  Python 3.10 / 3.11 / 3.12 / 3.13 test matrix is fully green.

## OCR lint / type fixes (PR #19)

The OCR integration commit (`a498ccc`) introduced several lint and
mypy violations plus a missing pytest marker. PR #19 cleaned all of them
without weakening CI:

- `src/normadocs/ocr.py`:
  - RUF046: removed redundant `int(round(...))` cast (`round()` already
    returns `int` in Python 3).
  - W292: added trailing newline.
  - Four `no-any-return` errors narrowed via `cast()` with short
    comments explaining the stub mismatch (no `# type: ignore`).
  - `import cv2` moved inside the functions that use it.
- `tests/test_ocr.py`:
  - I001: imports reformatted.
  - SIM117: nested `with` statements collapsed into a single
    multi-context `with`.
  - W292: added trailing newline.
  - `pytest.importorskip("cv2", ...)` at module level so the test file
    skips cleanly when OpenCV is not installed in CI.
  - `pytest.mark.skipif(shutil.which("tesseract") is None, ...)` on the
    end-to-end test so it runs only when tesseract is on PATH.
- `tests/test_cli.py`: replaced `runner.isolated_filesystem()` with
  `tempfile.TemporaryDirectory()` (the former was removed in
  typer 0.26 / click 8.4).
- `src/normadocs/utils/__init__.py`: `__all__` annotated as `list[str]`.
- `src/normadocs/formatters/ieee.py`: `table.style = "Table Grid"` narrowed
  via `cast(Any, ...)` with a justifying comment about the python-docx
  setter parameter type stub.

## Upgrade instructions

There is no required migration. To upgrade:

```bash
pip install --upgrade normadocs
```

The pre-existing `short_title` field in `DocumentMetadata` (already
shipped in the unreleased 0.2.2 work) and the new example
`examples/references.bib` are both additive.

To run the OCR end-to-end test locally, you need both the
`[ocr]` extra and the `tesseract` binary:

```bash
pip install -e ".[ocr,dev]"
# On Debian / Ubuntu:
sudo apt install tesseract-ocr tesseract-ocr-spa
```
