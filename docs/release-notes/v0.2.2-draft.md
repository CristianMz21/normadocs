## Title

`NormaDocs v0.2.2 — Open Source Readiness and Community Setup`

## Body

This release focuses on making NormaDocs a friendlier, more transparent open
source project for contributors and users. It does not introduce breaking
changes and does not change the public CLI or Python API.

### Added

- `SUPPORT.md` — how to ask usage questions, report bugs, request features,
  and report security issues.
- `GOVERNANCE.md` — maintainer-led governance model, decision process, and
  roadmap mechanics.
- `MAINTAINERS.md` — current maintainer, responsibilities, and criteria for
  future maintainers.
- `docs/COMMUNITY.md` — community channels and recommended Discussion
  categories.
- `examples/references.bib` — BibTeX example for the BibTeX → CSL → DOCX
  pipeline.
- GitHub issue template for documentation issues (alongside the existing bug
  report and feature request templates).
- GitHub labels for standards (APA, ICONTEC, IEEE, MLA), CI / testing /
  security, and community / roadmap work.
- GitHub milestones for the next three planned releases.
- GitHub Discussions enabled.

### Changed

- README expanded with `What is NormaDocs?`, `Why this exists`,
  `Ecosystem impact`, `Who it is for`, `Project status`, `Citation`, and a
  `Resources` section.
- Tightened `.github/SECURITY.md`: GitHub private vulnerability reporting is
  the primary channel; response SLA documented.
- Improved `.github/PULL_REQUEST_TEMPLATE.md` with program-relevant checklist
  items.
- Updated ROADMAP to match the three-phase (near / mid / long-term) structure.
- Repository description and topics updated on GitHub.

### Fixed

- `mypy` strict errors in `src/normadocs/utils/__init__.py` (`__all__`
  annotation) and `src/normadocs/formatters/ieee.py` (table style assignment
  with a justified `cast(Any, ...)` — no `# type: ignore`, no weakened
  strictness).
- Broken README link to contributor docs.
- `make check` is now fully green end-to-end (ruff, ruff format,
  mypy `--strict`, bandit, pytest with `--cov-fail-under=78`).

### Validation

- `mypy src/normadocs` — no issues found in 43 source files.
- `bandit -r src/normadocs` — no issues identified.

- `make build` — wheel and sdist built successfully.

### Notes
